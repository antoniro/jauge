# Savings are measured against a reference station: the closest by default, or one the person picks

Real savings need something to be compared with. We compare with the station the person would have gone to anyway. Nobody tells us which one that is, so we assume the closest station that sells their fuel, and let the person replace it: tapping a station that is not among the ranked cards, or pressing "Ma référence" on any station, makes it the reference, and everything is recalculated against it. Tapping a station that already has a card only selects it, because people tap those to see what they would save there, and turning each into the reference would show "0,00 $" instead.

An earlier version kept the closest station as the only reference and showed a picked station as a separate "your selection" card with a third row suggesting a better option. It mixed two comparisons in one card (savings against the closest, and a suggestion against the pick) and made cards change height. One reference at a time removed both problems.

## Considered options

- Compare with the average price nearby: rejected, an average is not a place you can drive to, so the detour has no meaning.
- Make every tapped station the reference: rejected for the reason above.
